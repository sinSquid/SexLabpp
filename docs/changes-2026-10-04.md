## 3. 今日累计修复与优化

### 3.1 存档、配置与异步持久化

- Statistics 改为显式类型与载荷的 v2 序列化，检查读取长度、数量和写入结果；保留 v1 MSVC x64 16 字节 variant 布局的迁移路径。无法解析 FormID 时仍消费完整记录，避免后续字段错位。
- 修复统计访问锁、计数初始化、遭遇记录快照、最新记录排序、Dominant/Submissive 方向、重置筛选及存档恢复问题；五个 uint8 遭遇计数采用饱和增长，避免溢出归零。
- Tracking 保持 v1 格式，增加数量/分隔符/截断检查、完整写入验证和加载临时容器；回调使用快照，减少锁与外部调用相互影响。
- SaveQueue 使用不可变快照、单写入者、路径合并及原子文件替换；Settings/StripData 在锁内取一致快照，在锁外进行文本生成和磁盘操作。
- StripData 删除和重置可正确落盘，保留尚未加载插件的数据；解析失败不破坏已有内存状态。编辑版本回执避免旧保存错误清除新修改的 dirty 状态。
- AsyncIO 关闭时排空已接受任务；线程启动失败不会留下假运行状态或滞留未接受任务，单个任务异常不会中断后续处理。
- Theme、语音导出及 ML INI 使用原子写入；RecordIO 正确处理空字符串、空 data 指针和非 NUL 结尾的 string_view，检查长度溢出与零步长。

### 3.2 线程生命周期、识别与 Papyrus

- Legacy/新识别器使用同步快照及受保护的所有权，读取结果按值保留，减少悬空引用和并发访问窗口。
- 线程启动失败、取消和 Papyrus AddActors 失败时清理状态；修复普通结束时的表达式标签处理。
- 修复识别滞回中的状态保持；NiMotion 在同帧按锚点缓存描述符，避免重复计算。
- 修正 ResetStatistics、ActionRev 等 native 注册契约；测试核对 286 个 native 声明与注册关系。
- ImGui 实例消失时恢复已压入的裁剪状态；删除语音时同步权威缓存。

### 3.3 动画匹配、图算法与 SLR 读取

- 必选演员匹配采用增广路径，避免贪心选择导致存在可行解却匹配失败；位置排序覆盖完整集合。
- 修复最短路径重建。无环图采用可达子图、拓扑顺序和长度/后继信息，避免递归复制整条路径；有环图采用显式栈和访问预算。
- 有环最长路径最多检查 **100,000 条边访问**，超限返回当前找到的最佳简单路径并提示；不保证超限场景的全局最长解。
- Decode::Reader 统一原始/类型化读取，共享剩余字节预算；构造时测量一次长度，支持非零起始偏移，先验证后分配。
- 修复有符号定点数解码，限制单字符串 1 MiB、包内场景 100,000、每组标签/注解 4,096；场景、阶段、位置与图关联增加有效性检查。
- YAML furnitureOffset、annotations 等字段保存和读取保持一致。
- 片段组合在部分结果阶段去重，减少重复完整组合生成；场景设置按 YAML 中实际键查表，避免遍历全部场景。

### 3.4 几何、动作与家具扫描

- 修复最近线段点公式与端点情形；PCA 使用独立初始方向和尺度处理，覆盖退化初值及微小动作。
- 反平行 RotateTowards 遵守旋转角度上限；投影夹角返回弧度，并处理零长度向量。
- 旋转 OBB 点内判断转入局部空间；SAT 修正分离轴、负投影、包含情形的位移及旋转盒角点。角点采用固定数组并为轴容器预留空间。
- 补齐默认坐标与 Havok 平移初始化，使用不要求额外对齐的 SIMD 存储；射线层编号验证后再进行 64 位移位。
- 家具引用切换和最近点选择使用正确引用及世界坐标。采样采用整数网格计数、有限值校验，每轴最多 **256** 个样本，每条射线最多 **64** 次跳过命中的尝试，重复命中停止，避免浮点步进或物理查询不终止。
- 减少 min/max 内部二次复制、语音和标签只读复制，降低高频日志等级。

### 3.5 资源加载、构建与辅助脚本

- 8 个 noexcept 资源枚举入口把目录构造、迭代和元数据读取异常纳入保护；目录检查使用错误码路径。
- 启动采用可回收线程，线程创建失败时同步完成剩余初始化；普通与 VR 分支都执行包含 FX 在内的五项初始化。
- FX 文件名仅接受规范 1–255 数字，拒绝前导零、符号和尾随字符，检查索引连续性，避免小整数计数溢出。
- MP3 转换先确认转换成功及临时输出非空，发布成功后才删除源文件；已有 WAV 时保留 MP3。
- Papyrus 源文件安装由重复注册改为一次，避免随文件数平方增长的重复工作。
- 新增可移植回归测试及 Linux/Windows CI 配置；本次未核验远端 CI 运行结果。

### 3.6 ML 数据与模型链路

- 固定 CSV 特征模式，缺失描述符填零；跨文件字段集合不一致时拒绝合并，同字段不同顺序可正常对齐。
- Softmax 使用完整 Interaction_Feature，采用 cluster-v2 导出；修复 sklearn 二分类转换、重复映射列和旧模式兼容处理。
- 合并完整 INI section，抑制不存在的类别；每次训练导出到独立 `out/models/run-*`，避免把旧文件混入新模型，无新导出时不合并。
- 支持满足条件的小型分层数据集；某类不足两个样本时跳过训练，目录与导出处理顺序确定化。
- 归档采用独占命名，处理编号空洞与并发发布；失败批次保留内存，后续状态变化和正常关闭时重试。
- 帧锁内移交样本，文本与磁盘工作放到锁外；ML 状态查询不再复制训练样本。

- 已落实的算法/分配改善包括：阈值二分查询、DAG 路径信息复用、读取字节预算缓存、片段去重、同帧描述符缓存、只读引用、较短锁区间和稀疏设置查表。
